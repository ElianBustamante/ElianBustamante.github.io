# Contributing Guidelines

Thanks for your interest in this project!

This repository is a personal portfolio and photography showcase, not a community or open-source product.

### Feedback and bug reports
- Bug reports, typo fixes, broken links, and accessibility improvements are always welcome.
- Please open an issue first to discuss any issue before working on a fix.
- Design overhauls or changes to personal content (written copy, photographs, projects) are not accepted.

### Proposing a fix
1. Fork the repository and create a new branch for your fix.
2. Ensure all checks pass locally by running `npm run check`.
3. Open a pull request describing the problem and your solution.

### Code and content reuse
- The web code is open source under the [MIT License](LICENSE).
- All photographs, media assets, and personal written copy are strictly all rights reserved (see [LICENSE-ASSETS.md](LICENSE-ASSETS.md)) and may not be copied, redistributed, or reused. Please do not submit third-party copyrighted materials.

Please ensure all interactions remain respectful and constructive.
