# Elian Bustamante | Desarrollo de software y fotografía de paisaje

Portafolio de Elian Bustamante: proyectos de software (bots, datos y web) y fotografía de paisaje.

## Stack
- React + Vite
- Tailwind CSS v4
- i18next

## Comandos
- `npm run dev`: Inicia el servidor de desarrollo.
- `npm run check`: Corre linter, tests y build.
- `npm run photos`: Procesa las imágenes originales y genera las versiones web. Crea o completa `src/data/captions.json` (versionado en git; `photos-originals/` sigue ignorada) con entradas vacías para las fotos nuevas. Si quedan fotos sin título en español, las lista para rellenarlas en el archivo y volver a ejecutar el comando.
